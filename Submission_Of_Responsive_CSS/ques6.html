Responsive CSS Cheat Sheet

Learn Important CSS Concepts

CSS Filters

CSS filters are used to apply visual effects to images like blur, grayscale and brightness.

filter: grayscale(100%);

Media Queries

Media queries apply different CSS styles according to screen size and device type.

@media (max-width: 700px)

Responsive Design

Responsive design makes websites adjust automatically to different screen sizes.

width: 100%;

Typography

Responsive typography adjusts font sizes to improve readability on different devices.

font-size: clamp(1rem, 4vw, 3rem);

CSS Grid

CSS Grid is a two-dimensional layout system used to arrange elements in rows and columns.

display: grid;

Flexbox

Flexbox is a one-dimensional layout system used to arrange elements horizontally or vertically.

display: flex;
