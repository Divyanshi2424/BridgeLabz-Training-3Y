3. Describe how a browser requests and displays a web page from a web server.
Ans. When a user opens a website, the following steps take place:
1.	Enter URL: The user enters a URL, such as www.example.com, in the browser. 
2.	DNS Lookup: The browser uses DNS to find the IP address of the web server. 
3.	Send Request: The browser sends an HTTP/HTTPS request to the web server for the required webpage. 
4.	Server Processing: The web server receives the request, processes it, and may retrieve data from a database. 
5.	Server Response: The server sends an HTTP/HTTPS response containing HTML and other required resources such as CSS, JavaScript, and images. 
6.	Browser Rendering: The browser processes the received HTML, CSS, and JavaScript and renders the webpage on the screen. 
Simple flow:
User → Browser → DNS → Web Server → HTTP Response → Browser → Web Page
Example: When you open an online shopping website, the browser requests the website from the server. The server processes the request and sends back the webpage and product data, which the browser displays to you.

6. Define the roles of a frontend developer, backend developer, and database administrator in a project.
Ans.
•	Frontend Developer: Creates the user interface and handles everything users see and interact with using HTML, CSS, and JavaScript. 
•	Backend Developer: Develops server-side logic, APIs, authentication, and handles communication between the frontend and database. 
•	Database Administrator (DBA): Manages databases, including storing, organizing, securing, backing up, and maintaining data. 
Flow:
Frontend → Backend → Database

9. Research and list five web browsers. Explain how rendering engines differ between
them.
Ans. 
Web Browser	Rendering Engine
Google Chrome	Blink
Microsoft Edge	Blink
Mozilla Firefox	Gecko

Opera	Blink
How they differ: Rendering engines convert HTML, CSS, and JavaScript into the webpage you see. Different engines may interpret web standards slightly differently, so the same website can sometimes look or behave differently across browsers.
Main engines:
Blink → Chrome, Edge, Opera
Gecko → Firefox
WebKit → Safari
